## 사용자 맞춤(Custom) 템플릿 적용 가이드

### 1. 나만의 캐릭터로 변경하고 싶을 때
- 방법 A (영구 교체): assets/character_reference.png 파일을 본인의 프로필 사진이나 캐리커처 이미지로 덮어씁니다.
- 방법 B (대화 중 교체): 대화 중에 "내 캐릭터 사진 첨부할 테니 이 인물로 카드뉴스 그려줘"라고 요청합니다.

### 2. 브랜딩 및 로고 문구 변경
- "표지에 내 브랜드명인 OO클래스, 웹사이트 example.com을 넣어줘"라고 지정하면 표지와 엔딩에 반영됩니다.
